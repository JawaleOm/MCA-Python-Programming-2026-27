# 🐍 MCA Python Programming (2026–27)

A comprehensive collection of Python programming practicals, exercises, and implementations developed as part of the **Master of Computer Applications (MCA)** curriculum for the academic year **2026–27**.

This repository contains unit-wise Python programs covering programming fundamentals, control structures, functions, modular programming, strings, collections, exception handling, file handling, and standard Python libraries.

The primary objective is to develop strong programming fundamentals, logical thinking, and practical problem-solving skills through hands-on implementation.

# ⚙️ Installation and Setup

Follow these steps to run the Python programs on your local machine.

### 1. Install Python

Download Python 3 from the official website:

https://www.python.org/downloads/

Verify installation:

```bash
python --version
```

### 2. Clone the Repository

```bash
git clone https://github.com/JawaleOm/MCA-Python-Programming-2026-27.git
```

### 3. Navigate to the Repository

```bash
cd MCA-Python-Programming-2026-27
```

### 4. Open in Visual Studio Code

```bash
code .
```

### 5. Run a Python Program

Example – Unit 01:

```bash
cd Unit-01-Foundations-and-Control-Structures
python P01_marks_calculation.py
```

Example – Unit 02:

```bash
cd ../Unit-02-Functions-and-Modular-Programming
python P01_Arithmetic_Functions.py
```

Example – Unit 03:

```bash
cd ../Unit-03-Strings-and-Python-Collections
python P01_Strings_and_String_Methods.py
```

Example – Unit 04:

```bash
cd ../Unit-04-Exception-File-and-Standard-Libraries
python P01_Exception_Handling.py
```
